# Michael Odedipe — AI photography portfolio

Static React / TypeScript / Vite source. See `../START-HERE.md` in the delivery package for publishing instructions.

Use Node >=22.13.0. `npm ci`, then `npm run dev`. Validation: `npm run check` and `npm run verify:content`. Production build: `npm run build` → `dist/`. GitHub Pages workflow: `.github/workflows/pages.yml`; enable GitHub Actions as the Pages source.

All paths are relative to support a GitHub repository subpath. Contact drafts use mailto and do not require a server. No private credentials, external fonts, image hotlinks, database bindings, or reference-site assets are included.
